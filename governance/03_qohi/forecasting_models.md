# Forecasting Models

Version: 0.1.0

## Purpose

This file defines approved forecasting categories for QOHI™ support.

## Approved Categories

- Economic modeling
- Infrastructure planning
- Long-range scenario simulations
- Risk and dependency mapping
- Operational readiness projections

## Required Disclosures

Forecasts are not guarantees. Outputs must identify assumptions, uncertainty, input limitations, and required human review.
